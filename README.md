# City High Jazz Ensemble · IBA 2026

Mobile concert program for the Iowa City High School Jazz Ensemble at the
97th Iowa Bandmasters Association Conference — Thursday, May 14, 2026.

Goal: 750 QR-scanned mobile programs instead of 750 paper ones.

## Files

- `index.html` — the entire program (single-file, no build step)
- `sw.js` — service worker for offline / saturated-WiFi resilience
- `manifest.webmanifest` — PWA install metadata
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Deploy

GitHub Pages, `main` branch, root folder. The QR code on signage should
point at the Pages URL.
